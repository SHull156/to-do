# to-do

to-do is a lightwight to-do list generator. It allows users to add new items and then track each item through to completion.


# Key idea
- Built to allow the user to track all outstanding tasks in one place

# Tech stack
- HTML
- CSS
- Vanilla JavaScript

# Features
- **Dynamic plan generation**
- Input todo text
- Move todo item through outstanding, in process and completed statuses
- Items can be deleted by clicking the delete button next to each item

- **Local persistence (no login)**
- Generated plans persist across page reloads using `localStorage`
- The same todo list is restored exactly as generated
